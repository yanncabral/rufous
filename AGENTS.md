# Orientações para agentes

Ao escrever ou alterar código Dart neste projeto:

- Use **primary constructors** sempre que possível.
- Use **dot shorthand** sempre que possível.
- Prefira **pattern matching** sempre que possível.

Aplique essas convenções quando melhorarem a legibilidade e forem compatíveis com a versão e a configuração do Dart adotadas pelo projeto. Não force seu uso em casos inadequados ou quando tornarem o código menos claro.
